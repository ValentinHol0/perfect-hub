# i18n file formats — translator's cheat sheet

Sources checked 2026-11-12: i18next plurals (https://www.i18next.com/translation-function/plurals), ICU messages (https://unicode-org.github.io/icu/userguide/format_parse/messages/), Android string resources (https://developer.android.com/guide/topics/resources/string-resource), Xcode String Catalogs (https://developer.apple.com/documentation/xcode/localizing-and-varying-text-with-a-string-catalog). Items marked `[Unverified]` were not confirmed in those pages.

## 1. i18next JSON (v21+, "JSON v4")
```json
{
  "cart": {
    "title": "Кошик",
    "items_one": "{{count}} товар",
    "items_few": "{{count}} товари",
    "items_many": "{{count}} товарів",
    "items_other": "{{count}} товару",
    "greeting": "Вітаємо, {{name}}!",
    "terms": "Погоджуюся з <1>умовами</1>"
  }
}
```
- Interpolation `{{name}}`; the plural variable must be called `count`. `{{- html}}` = unescaped value `[Unverified syntax detail — check the project's i18next version]`.
- Plural suffixes follow `Intl.PluralRules`; since v24 there is no fallback without `Intl.PluralRules`. Old v3 files use `key` / `key_plural` / `key_0` — do not mix formats in one project; ask which version the code runs.
- `<1>…</1>` = react-i18next `Trans` component index: keep numbers and nesting, move them with the words.
- Context: `friend_male`, `friend_female` — translate each; they are not plural forms.

## 2. ICU MessageFormat (FormatJS/react-intl, Angular/ICU, Java/ICU4J, Android API 24+)
```
{count, plural,
  =0 {Кошик порожній}
  one {У кошику # товар}
  few {У кошику # товари}
  many {У кошику # товарів}
  other {У кошику # товару}}
```
- `#` prints the number inside plural/selectordinal branches; `=0` is an exact match and does not replace the `one` category.
- ICU recommends complex arguments as the outermost structure with full sentences inside branches; put `select` outside and `plural` inside.
- Apostrophe: since ICU 4.8 an ASCII `'` starts quoted text only before a special character (`{`, `}`, `#` in plurals); `''` prints one apostrophe. In Ukrainian text use ’ (U+2019), which ICU never treats as syntax.
- Typed arguments `{price, number, ::currency/UAH}`, `{d, date, long}` — translate nothing inside the braces.

## 3. gettext .po
```
#. Button on the checkout page, max 20 characters
#: src/checkout.js:42
msgctxt "button"
msgid "Pay %s"
msgstr "Сплатити %s"

msgid "%d file"
msgid_plural "%d files"
msgstr[0] "%d файл"
msgstr[1] "%d файли"
msgstr[2] "%d файлів"
```
- `#.` extracted comment (developer note) · `#:` source reference · `#,` flags: `fuzzy` (ignored at compile time — remove after review), `c-format`, `python-format` (`%(name)s`).
- Header `Language: uk` and `Plural-Forms` (3 forms for Ukrainian — see `plural-rules.md`).
- `.pot` is the template (empty msgstr); translate into `uk.po`. Multi-line strings: `""` then continuation lines.

## 4. Android `res/values-uk/strings.xml`
```xml
<resources>
    <string name="welcome">Вітаємо, %1$s! Нових повідомлень: %2$d.</string>
    <string name="apostrophe">Об\'єднати акаунти</string>
    <plurals name="songs_found">
        <item quantity="one">Знайдено %d пісню</item>
        <item quantity="few">Знайдено %d пісні</item>
        <item quantity="many">Знайдено %d пісень</item>
        <item quantity="other">Знайдено %d пісні</item>
    </plurals>
</resources>
```
- Escape `'` as `\'` (or quote the whole string), `"` as `\"`, leading `@` / `?` as `\@` / `\?`; `\n` newline; whitespace collapses unless the string is in double quotes. A typographic ’ (U+2019) needs no escaping.
- Supported quantities: zero, one, two, few, many, other; selection is by grammar only (English ignores `zero` even for 0). Android's own Polish example supplies one/few/other — supply every CLDR category anyway.
- Positional args `%1$s`, `%2$d` may move within the sentence; plain `%s` may not.
- Allowed styling tags include `<b>`, `<i>`, `<u>`, `<s>`, `<sup>`, `<sub>`, `<br>`, `<font>`, `<annotation>` (keep annotations around the equivalent words).
- `translatable="false"` strings stay as they are; `<xliff:g id="…">` marks untranslatable parts `[Unverified in the fetched page — keep the tags unchanged]`.

## 5. iOS / macOS
- **String Catalog `.xcstrings`** (one file for all languages; introduced with Xcode 15 `[Unverified]`): states New → Translated in the editor; "Vary by Plural" adds language-specific plural variations; `%lld` = 64-bit integer, `%@` = object/string. Comments for translators can be auto-generated by Xcode — a human comment always wins.
- **Legacy `.strings`**: `"checkout.pay" = "Сплатити %@";` — escape `"` as `\"`, keep the semicolon; `/* comment */` above is the translator note.
- **Legacy `.stringsdict`** (plist with `NSStringLocalizedFormatKey`, `%#@items@`, `NSStringPluralRuleType`, keys `one`/`few`/`many`/`other`) `[Unverified structure details — follow the project file]`.
- Positional specifiers `%1$@`, `%2$lld` allow reordering.

## 6. What check-i18n covers
JSON (nested, flat, i18next plurals, ICU values) and .po/.pot. For Android/iOS, compare key sets and placeholders manually with the rules above, or ask the core to export to XLIFF/JSON first.
