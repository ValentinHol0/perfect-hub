# Social Strategy

A strategy is a set of choices: who we talk to, what we repeatedly say, where, how often, and how we know it works. References:
- `${CLAUDE_PLUGIN_ROOT}/skills/social/references/strategy/platforms.md` — role of each platform, formats, verified limits, Ukrainian media context, with sources and check dates.
- `${CLAUDE_PLUGIN_ROOT}/skills/social/references/strategy/strategy-template.md` — the document to fill (`deliverables/social/<slug>/strategy.md`).

## 1. Goal and KPIs
One primary goal for 90 days, measured on the platform and in the business:
| Goal | Primary KPI (platform) | Business check |
|---|---|---|
| Sales / leads | link clicks, DMs with intent, profile visits → site | orders/leads attributed via UTM or "Звідки ви про нас дізналися?" |
| Awareness in a new segment | reach to non-followers, views, shares | branded search, direct traffic |
| Community / retention | comments per post, saves, repeat commenters, Telegram ERR | repeat purchases, referrals |
| Launch | reach in launch week, waitlist sign-ups | pre-orders |
| Hiring / employer brand | profile visits, applications from social | hires |
Set targets from the account's own baseline (last 90 days in native analytics). No baseline → set a first-month learning target and say so; never quote "industry average engagement" without a cited source.

## 2. Audience in their words
- 1–3 segments: who, situation, what they want, what stops them, where they scroll and when.
- Collect real language: comments on own and competitor posts, reviews on Rozetka/Prom/Google Maps, Telegram chats, Reddit/forums. Quote phrases verbatim in the strategy (with source) — these become hooks.
- Objection list (top 5) → each gets a recurring content answer.

## 3. Content pillars (3–5)
Each pillar: name · purpose (which goal it serves) · share of posts · formats · 3 example topics · proof assets it needs.
Starting mix for a product brand (adjust by goal, then by results): value/education 35–45 % · product in use and proof 25–35 % · community/people/behind the scenes 15–25 % · direct offers 5–15 %. Offers above ~20 % of posts usually train the audience to ignore the feed — treat as a house rule to test, not a statistic.
Pillar test: could a competitor post the same pillar unchanged? If yes, add the brand's specific angle (founder's expertise, production, local context, data only this brand has).

## 4. Platform choice
Use the role table in `platforms.md`. Decide per platform: **role** (discover / convert / retain / support), **format mix**, **cadence**, **owner**. Rules:
- Start with 2–3 platforms done well; add one only when the first ones run on schedule for a month.
- Ukrainian audiences: evaluate a **Telegram channel** for every brand — it is the leading social platform for news in Ukraine (Internews 2025 survey, `platforms.md`) and works as an owned broadcast channel; pair it with a discovery platform (Reels/TikTok/Shorts).
- B2B and hiring → LinkedIn (+ Telegram for the founder's voice). Local services → Instagram + Google Business Profile + Facebook for older audiences. Youth → TikTok + Instagram Reels + YouTube Shorts.
- One video can serve Reels, TikTok and Shorts — edit natively per platform (no watermarks from another app, native text and sounds).

## 5. Cadence (sustainable tiers — starting points, then follow the data)
| Platform | Minimum | Standard | Growth |
|---|---|---|---|
| Instagram feed (Reels + carousels) | 2/week | 3–4/week | 5+/week |
| Instagram Stories | 3 days/week | daily | daily, 3–7 frames |
| TikTok | 2/week | 3–5/week | daily |
| YouTube Shorts | 1/week (repurposed) | 2–3/week | daily |
| Telegram channel | 3/week | 5/week | 1–3/day (news-type channels) |
| Facebook | 2/week | 3–5/week | daily |
| Threads | 3/week | daily | several/day |
| LinkedIn (person or page) | 1/week | 2–3/week | daily (person) |
These are planning tiers, not platform rules or research figures. Pick the tier the team can produce for 90 days without gaps; consistency over volume. Then generate the calendar with `references/calendar.md`.

## 6. Voice on social
3 principles with "ми пишемо / ми не пишемо" pairs; address form (ви/ти); emoji policy (none / functional only / expressive); humour boundaries; words banned; how the brand speaks about the war, mobilisation, outages and mourning (default: respectfully, without using them for promotion). Copy quality: `${CLAUDE_PLUGIN_ROOT}/skills/social/references/posts/ukrainian-copy.md`.

## 7. 90-day plan
Month 1: set up profiles (bio, highlights, pinned posts, link), baseline metrics, first pillars in production, 2 experiments. Month 2: double down on formats that beat the baseline, cut the bottom quarter. Month 3: scale winners, test one new format or platform. Each experiment: hypothesis · change · metric · decision date.
