# Hooks, CTAs and carousel structures

Every example is a pattern to adapt; numbers and claims in a real post must be true for the brand.

## 1. Hook formulas
| Formula | Example (UA) | Works for |
|---|---|---|
| Specific result + time | «Як ми скоротили повернення з Нової пошти вдвічі за місяць» (only with real data) | case studies, B2B |
| Mistake list | «3 помилки, через які кава в турці гірчить» | education, saves |
| Contrast / myth | «Дорожча ковдра — не тепліша. Ось що насправді гріє» | education, shares |
| Direct callout | «Якщо ви вперше замовляєте меблі онлайн — прочитайте це» | segmenting |
| Question with stakes | «Скільки ви переплачуєте за доставку щомісяця?» | engagement |
| Before → after (real) | «Було: 40 хв на прибирання кухні. Стало: 15» | product proof |
| Behind the scenes | «Що відбувається з вашим замовленням між кліком і пакуванням» | trust |
| Number + promise | «7 способів продовжити життя кросівок» | saves |
| Hot take (brand-safe) | «Знижки щотижня вбивають довіру до бренду. Ми відмовились» | opinion, Threads/LinkedIn |
| Story opening | «У вересні до нас прийшла посилка без жодної записки» | community, founder voice |
| Local / timely | «У Львові знову −10. Ось як не застудити руки за кермом» | reach, relevance |
Ban: «Друзі!», «Всім привіт!», «Хочемо поділитися…», «Ви не повірите…», clickbait the body doesn't pay off, fake urgency.

## 2. CTA bank by job
| Job | CTA examples |
|---|---|
| Save | «Збережіть, щоб повернутися перед покупкою» |
| Share | «Надішліть другу, який досі заварює окропом» |
| Comment | «Яку помилку робили ви? Напишіть номер» · «Що обрали б: А чи Б?» |
| DM | «Напишіть "розмір" у Direct — підберемо за 5 хвилин» (only if someone will reply that fast) |
| Click | «Повний гайд — за посиланням у профілі» · Telegram: «Читати повністю →» with a labelled link |
| Buy | «Замовлення до 14:00 — відправимо сьогодні Новою поштою» (only if true) |
One CTA per post. Comment CTAs must be answerable in a few words.

## 3. Carousel structures
| Structure | Slides |
|---|---|
| Mistakes / tips | cover hook → 1 point per slide (problem → fix) → summary → CTA |
| Step-by-step guide | cover result → what you need → steps 1…n → common mistake → CTA save |
| Myth vs fact | cover → myth/fact pairs → source/proof → CTA share |
| Comparison | cover question → criteria → A vs B per criterion → verdict → CTA |
| Story | cover moment → setup → conflict → turn → lesson → CTA |
| Product explainer | cover problem → how it works → details/materials → real use → price/delivery → CTA |
Rules: cover ≤ 8 words; ≤ 25 words per inner slide; visual continuity across slides; the last slide gives a reason to save or act; the caption adds context (not a transcript of the slides).

## 4. Telegram post patterns
- **Expert note:** bold headline line → 3–5 short paragraphs → takeaway → question or link.
- **Digest:** bold title → 3–5 items with one-line comment each → «Що з цього вам ближче?».
- **Product drop:** photo album (up to the platform limit) → caption with price, sizes, delivery → how to order (bot/DM/site).
- **Poll:** a real decision the audience influences (next flavour, colour), with results posted later.

## 5. Hook quality test
- Would the target reader stop? (specific to them, not generic)
- Is it true, and does the body pay it off?
- Under ~125 characters, readable without the image?
- No banned openers, no Russianisms (`ukrainian-copy.md`)?
