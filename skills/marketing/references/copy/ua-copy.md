# Ukrainian copy quality

Marketing Ukrainian should read like a good native editor wrote it for a customer, not like a translation from Russian or English. Run this file over every Ukrainian deliverable.

Norm sources: «Український правопис» (2019 edition, approved by Cabinet of Ministers resolution No. 437 of 22.05.2019; official PDF: https://mon.gov.ua/static-objects/mon/sites/1/zagalna%20serednya/Pravopys.2019/ukr.pravopys-2019.pdf — located 2026-11-12, text not re-read here) and the classic usage guide by Б. Антоненко-Давидович «Як ми говоримо». Section numbers are not quoted from memory; check the source when a rule is disputed.

## 1. Calques to replace
Russianisms (left) are the most common tell of careless or machine-made Ukrainian.
| Avoid | Write |
|---|---|
| на протязі тижня | протягом тижня |
| приймати участь | брати участь |
| являється | є |
| слідуючий крок | наступний крок |
| співпадати, співпадіння | збігатися, збіг |
| вірно (= correct) | правильно |
| згідно наказу / закону | згідно з наказом, відповідно до закону |
| приймати міри | вживати заходів |
| міроприємство | захід |
| по питанню доставки | щодо доставки, з питання доставки |
| на рахунок оплати | щодо оплати |
| любий (= any) товар | будь-який товар |
| даний товар | цей товар |
| відмінити заказ | скасувати замовлення |
| ціна складає | ціна становить |
| задати питання | поставити запитання |
| вибачаюсь | перепрошую, вибачте |
| пройти по посиланню | перейти за посиланням |
| по акції, по ціні | за акцією, за ціною |
| слідкуйте за новинами | стежте за новинами |
| не дивлячись на | незважаючи на |
| самий кращий, більш кращий | найкращий, кращий |
| получити | отримати |
| при наявності, при умові | за наявності, за умови |
| на сьогоднішній день | сьогодні, нині |
| в якості подарунка | як подарунок |
| відноситься до | стосується, належить до |

Anglicisms and English sentence shapes (typical of AI drafts):
| Avoid | Write |
|---|---|
| Отримайте свою знижку | Отримайте знижку (drop the redundant possessive) |
| на щоденній основі | щодня |
| в той же час | водночас, тим часом |
| Будьте першим, хто дізнається | Дізнайтеся першими |
| Зробіть різницю | name the concrete effect |
| Відкрийте для себе…, Насолоджуйтесь… | say what the reader gets |
| Це не про X, це про Y | state Y directly |
| аплікувати, апплікація | подати заявку, застосунок |
| Ваша безпека — наш пріоритет | name the actual measure (e.g. "оплата через LiqPay, дані картки ми не зберігаємо" — only if true) |

Impersonal and nominal style reads like a government notice:
- "Доставка здійснюється Новою Поштою" → "Доставляємо Новою Поштою".
- "Оплата проводиться при отриманні" → "Оплатити можна під час отримання".
- Chains of verbal nouns ("здійснення оформлення замовлення") → a verb ("оформити замовлення").

## 2. Voice and address
- Decide ти or ви once per brand and keep it everywhere (site, email, ads, bot). Ти suits young, informal brands; ви is the safe default.
- Capitalised "Ви" is a courtesy form for one person in a personal letter; in mass marketing copy write lowercase "ви".
- Feminitives (авторка, експертка, клієнтка) are part of the 2019 orthography; using them is a brand-voice decision — be consistent.
- Imperatives: "Замовте" (ви) / "Замов" (ти). Not "Замовляйте" unless the action repeats.
- Avoid surzhyk and Russian words in transliteration unless the brand voice is deliberately colloquial and the user asked for it.

## 3. Typography
| Item | Rule |
|---|---|
| Quotes | «ялинки»; nested „лапки“ |
| Apostrophe | ’ (U+2019) or ʼ (U+02BC) consistently; never a straight ' in published copy |
| Dash | — with spaces in sentences ("Доставка — 1–2 дні"); ranges with an en dash and no spaces (1–2 дні, 10:00–18:00) |
| Prices | `1 299 грн` — non-breaking space between thousands and before "грн"; "₴" fits UI labels; "UAH" only in B2B documents |
| Decimals | comma: `4,5 кг` |
| Dates and time | `12 листопада 2026 р.` or `12.11.2026`; `16:00` |
| Phone | `+380 67 123 45 67` |
| Percent | pick `15 %` or `15%` per brand and keep it |
| Ellipsis, exclamation | at most one "!" per screen; no "!!!", no "..." for drama |
| Emoji | only if the brand voice uses them on that channel; never in headlines of landing pages |

## 4. Ukrainian AI-copy tells (rewrite, don't soften)
"У сучасному світі…", "Ідеальне рішення для…", "Неперевершена якість", "Широкий асортимент", "Найкращі ціни", "Якісно та швидко", "Індивідуальний підхід до кожного клієнта", "Команда професіоналів з багаторічним досвідом", "Розкрийте свій потенціал", "Вийдіть на новий рівень", "Трансформуйте свій бізнес", "Революційний", "Інноваційний", "Безшовний", "Зануртеся у світ…", "Не просто X, а Y" (more than twice), triplets of adjectives ("стильний, зручний та практичний"), every paragraph ending in a rhetorical question.

## 5. Read-aloud test
Read the copy out loud as a shop assistant talking to a customer. Every phrase you would never say to a person gets rewritten. Then check: numbers formatted, one ти/ви form, no calques from §1, quotes and apostrophes typographic.
