# Concept methods, symbol logic and visual modes

Ideas adapted (rewritten, not copied) from the MIT-licensed `brandkit` skill by Leonxlnx — credited in the README.

## 1. Five concept methods (combine at most two)
| Method | How it works | Done well | Done badly |
|---|---|---|---|
| **Monogram with meaning** | The initial carries a second idea through a cut, fold, counter or extension | "К" whose diagonal becomes a kite string; "N" folded like a path | A letter in a circle or shield with nothing else going on |
| **Product action** | The verb the product performs becomes the shape: build → frame, protect → boundary, convert → switch, speak → wave, automate → loop | A delivery service mark built from a box flap that reads as an arrow | Literal clip-art of the product (a truck, a cup) |
| **Metaphor fusion** | Two meaningful ideas reduced into one form | shield + mountain, moon + sound wave, seal + dog for a compliance tool | Two pictures glued together; needs explaining |
| **Negative space** | The empty area forms the second reading | hidden arrow, protected centre, eye formed by crossing shapes | Hairline gaps that close up at 16 px |
| **Construction geometry** | A visible system: circles, diagonals, modular blocks, orbits, grids | A mark you could redraw from a three-line construction note | Decorative "sacred geometry" without meaning |

Test every mark: can a stranger redraw it from memory after 10 seconds? Does it still read in one colour at 16 px?

## 2. Category → symbol logic (starting points, never defaults)
| Category | Core ideas | Possible symbol logic |
|---|---|---|
| Developer tools, automation | building, speed, precision, control | cursor, frame, scaffold, bracket, grid |
| AI assistants | delegation, clarity, intelligence | path, orbit, signal, node, spark (only if justified) |
| Security, compliance | protection, vigilance, boundary, order | shield, seal, eye, protected core, stamp |
| Voice, communication | sound, rhythm, flow | waveform, pulse ring, speech path |
| Logistics, delivery (Nova Poshta-style category) | speed, reliability, route | route line, box geometry, arrow in negative space |
| Food, cafés | ritual, warmth, origin | vessel, steam, hand-drawn letter, local landmark abstraction |
| Beauty, fashion, hospitality | taste, material, restraint | monogram, seal, petal, vessel, embossed wordmark |
| Agro, organic (strong Ukrainian category) | land, growth, season | field rows, seed, horizon, sun arc — avoid the generic leaf |
| Education | progress, curiosity, clarity | steps, open book abstraction, path, light (no owl-in-glasses) |
| Wellness, travel, climate | calm, direction, trust | horizon, compass, path, folded mark |
Pick symbols for a reason written in the strategy line, not because the category "usually" uses them.

## 3. Visual modes (choose by the brand, then customise)
| Mode | Use for | Cues | Mood |
|---|---|---|---|
| Dark builder | dev tools, infra, automation | near-black panels, monospace accents, terminal and prompt bars, subtle grid; cyan/lime/coral accent | precise, builder-native |
| Dark operator | sales, growth, productivity tools | black with amber/red, UI chips, segmented flows, progress motifs | fast, tactical |
| Calm nature | wellness, travel, strategy, climate | deep green + lime, misty landscapes, soft overlays, editorial grid | calm, trustworthy |
| Vigilant security | security, monitoring | black/navy, shield forms, radar lines, restrained alert colours | serious, precise |
| Light editorial | legal, finance, documents, public services | warm ivory, paper texture, small serif labels, seals; deep blue/red/gold | institutional but modern |
| Luxury | beauty, fashion, hospitality | ivory/stone/espresso, serif wordmark, monogram, emboss, paper grain | adult, expensive |
| Cultural / experimental | music, events, games, creative tools | halftone, CRT or print texture, poster panels, one loud accent | memorable, controlled |
| Warm local | cafés, bakeries, craft, family business | hand-set or rounded type, earthy palette, real-material photography | honest, close |

## 4. Anti-generic rules
Never deliver: random floating icons, startup gradients as the idea, meaningless blobs, sparkles without reason, lightning bolts without a speed story, fake luxury crests, clip-art animals, near-copies of famous marks, inconsistent variants of the mark, rainbow palettes (unless the brief asks), purple-blue "AI glow" by default, stock-template brand boards. Make it quieter, sharper and more intentional.

## 5. Taglines (if the identity needs one)
Short and specific; 2–5 words; no buzzwords. Pattern ideas: a promise ("Кожна посилка — вчасно"), a stance ("Нічого випадкового"), a question to the user ("Що збудуєте сьогодні?"). Avoid generic corporate lines ("Якість, якій довіряють", "Ваш надійний партнер").
